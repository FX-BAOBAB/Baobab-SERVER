
# 🌴 AR/AI를 이용한 물품보관 및 중고거래 플랫폼, Baobab
- AR/AI 를 활용한 물품 보관과 중고거래 플랫폼은 도시 생활자를 위한 혁신적인 서비스로, 편리한 보관 및 이동 솔루션과 중고 물품 거래를 통해 효율적인 자원 활용과 지속 가능한 소비를 장려
- 도시 생활의 불편함을 해소하고 새로운 보관 문화 선도
- AR 을 통해 보관 물품을 쉽게 확인 가능
